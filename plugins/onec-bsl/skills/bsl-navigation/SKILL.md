# Навигация по исходникам 1С

Выгрузки 1С содержат десятки тысяч файлов: `rg` по `src/cf/<конфигурация>` не укладывается в 120 с и съедает контекст. Сначала выбрать инструмент по виду факта. Если в проекте есть собственный регламент поиска (например, в `AGENTS.md`, `CLAUDE.md` или документации для агентов), он главнее этой таблицы.

В таблице `<сервер>` — имя, под которым MCP-сервер bsl-analyzer подключён в проекте (например, `bsl-analyzer-workspace`). Плагин не задаёт это имя; если MCP-сервера анализатора нет, использовать `LSP`.

| Искомый факт | Инструмент |
|---|---|
| Определение, сигнатура, описание известного символа | `LSP` (`goToDefinition`, `hover`) из открытого `.bsl` или `mcp__<сервер>__symbol_info` |
| Места использования символа | `mcp__<сервер>__symbol_info` (usages) или `graph`; `LSP findReferences` только в небольшой конфигурации |
| Кто вызывает и на что влияет изменение | `mcp__<сервер>__graph` (начинать с `overview`) |
| Реализация по смыслу или неизвестное имя | `mcp__<сервер>__search`, затем чтение найденного файла |
| Карта одного модуля | `mcp__<сервер>__outline` или `LSP documentSymbol` |
| Объекты, реквизиты, типы, табличные части, формы | `mcp__<сервер>__metadata` |
| Документация, OpenSpec, скрипты | семантический индекс репозитория или `rg` вне выгрузок |

Правила:

- Ответ `loading` или retry-конверт анализатора означает «повторить позже» через `status`, а не «данных нет»; не переходить на grep.
- Имя MCP-сервера анализатора задаёт проект; если серверов несколько (по одному на конфигурацию), выбирать сервер нужной конфигурации.
- Поиск в одном известном файле (`rg -n 'Имя' путь/Module.bsl`) разрешён.
- Список имён файлов в выгрузке — только с ограничением: `rg --files <каталог> | rg 'Имя' | head -50` или `find <каталог> -maxdepth 2`.
- Если анализатор не видит нужные файлы (worktree, свежая выгрузка вне индекса), широкий поиск выполнять с явной причиной: `BSL_GREP_REASON='worktree вне индекса' rg -n 'Имя' <каталог>`.
- Найденное индексом подтверждать чтением исходника; отсутствие результата не доказывает отсутствие кода.
